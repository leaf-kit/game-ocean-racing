# 배경음악 폴더

이 폴더에 음악 파일을 넣으면 게임이 자동으로 배경음악으로 재생합니다.
(저작권이 있는 음원은 직접 소장한 파일만 넣어 주세요. 게임에는 포함되어 있지 않습니다.)

## 방법 1 — 파일 하나
`bgm.mp3` 라는 이름으로 저장합니다. 자동으로 반복 재생됩니다.

```
assets/music/bgm.mp3
```

## 방법 2 — 여러 곡 (플레이리스트)
파일들을 이 폴더에 넣고 `playlist.json` 에 적습니다. `main` 은 메인 테마곡으로 타이틀·함선 선택·결과 화면에서 반복 재생되고, 레이스가 시작되면 `tracks` 중 한 곡이 무작위로 재생됩니다(직전 곡은 피함). 레이스가 끝나면 다시 메인 테마로 돌아옵니다.

```json
{ "main": "메인테마.mp3", "tracks": ["출항.mp3", "대양.mp3", "폭풍.ogg"] }
```

단순 배열(`["a.mp3", "b.mp3"]`)로 적으면 전곡이 무작위 순서로 재생됩니다.

mp3, ogg, m4a, wav 등 브라우저가 재생할 수 있는 형식이면 됩니다.
파일이 없으면 내장 합성 뱃노래가 재생됩니다. 게임 중 `M` 키로 음악을 켜고 끌 수 있습니다.
